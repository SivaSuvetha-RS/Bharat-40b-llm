Bharat-40B-LLM

India-First Foundation Model Proposal

Building an India-First 40B Large Language Model

Bharat-40B-LLM is designed to excel in coding, multilingual reasoning, Indian languages, mathematics, science and agentic workflows while preserving Indian knowledge and culture.

📚 Data Collection

Curated multilingual web data, books, government documents, Wikipedia, Bharat Stack resources, code repositories and STEM datasets.

🧹 Data Cleaning

Deduplication, language identification, quality filtering, toxicity removal, PII removal and benchmark decontamination.

🎯 Model Objectives

Strong reasoning, coding, Indian language understanding, mathematics, science and agentic AI.

📊 Evaluation

MMLU, GSM8K, HumanEval, IndicGenBench, BharatBench and multilingual QA.
