Bharat-40B Large Language Model

Designing an India-First multilingual foundation model capable of strong reasoning, coding, mathematics, science and agentic AI.

Project Overview

Objective

Build a 40 Billion parameter foundation model focused on Indian languages, software engineering, mathematical reasoning and scientific understanding.

Target Users

Students, developers, researchers, enterprises and public sector organisations.

Core Features

  • Multilingual Support
  • Indian Knowledge
  • Programming Assistance
  • Mathematical Reasoning
  • Agentic AI

Dataset Collection Strategy

Dataset Purpose
Indic Web, News, and Local Content Build an India-first worldview and strong regional language fluency in Hindi, Bengali, Marathi, Tamil, Telugu, Gujarati, Kannada, Malayalam, and Sanskrit-adjacent content.
Open English and Global Scientific Texts Provide general knowledge, scientific reasoning, math, and international context while preserving global quality.
Code Repositories, Q&A, and Docs Train coding ability, debugging patterns, API knowledge, and agentic software workflows across Python, JavaScript, Java, C++, SQL, and shell scripting.
STEM Education Content Ground mathematical reasoning, physics, chemistry, and biology with NCERT, Olympiad, and Indian university course materials.
Government and Public Domain Data Align to Indian policy, law, civic services, and cultural norms through authentic public-sector sources.
Instruction and Agentic Interaction Data Support task planning, agentic workflows, conversational assistants, Code-Ally behavior, and Indian conversational style.
RLHF and Alignment Annotations Refine safety, preference alignment, truthfulness, and India-first helpfulness with human feedback and critique labels.

The training data is split to favor Indian languages and worldview without sacrificing strong coding, math, and global reasoning performance. This balance is essential for a 40B model that is both India-first and broadly capable.

Data & Task Fertility

Language Fertility

Target data balance for Indic fluency and global competency:

  • Hindi: 25%
  • Bengali: 10%
  • Marathi: 8%
  • Tamil: 8%
  • Telugu: 8%
  • Gujarati: 6%
  • Kannada: 6%
  • Malayalam: 6%
  • Punjabi: 6%
  • Other Indic languages & Sanskrit-adjacent text: 7%
  • English and global content: 30%

This distribution gives strong regional Indic coverage while retaining robust English and global scientific content.

Task Fertility

  • Coding & Development: 30%
  • Science & Math Reasoning: 20%
  • Indian Knowledge & Civic Content: 20%
  • Agentic / Instructional Tasks: 20%
  • Safety & Alignment Signals: 10%

These weights prioritize coding and agentic strength while keeping strong academic and localisation capability.

Tokenizer Design

Recommended token vocabulary size: 120,000.

Rationale: This size supports Indic scripts, code tokens, mixed-language prompt patterns, and STEM notation without excessive token fragmentation.

Evaluation Strategy

Benchmark Purpose
MMLU, PIQA, BBH General reasoning and common-sense understanding.
HumanEval, CodeXGLUE, MBPP Programming performance across multiple languages and problem types.
GSM8K, MATH, ARC Mathematics, science reasoning, and problem-solving accuracy.
IndicBench, IndicNLP, FLORES Indian language comprehension, translation, and generative quality.
GAIA, custom Indian agentic task sets Agentic planning, task execution, and India-first contextual assistance.

Evaluation includes both standard benchmarks and bespoke Indian-context tests to ensure the model is locally relevant, safe, and strong in coding and agentic tasks.
